# 📊 Employee Attrition Analysis – Power BI Dashboard

## 📝 Project Description
This project focuses on analysing employee attrition and workforce trends using Microsoft Power BI. The dashboard provides insights into employee turnover, department-wise attrition, age groups, overtime, job satisfaction, and other HR metrics.

🎯 **Objective:** Help HR teams understand workforce patterns, identify areas with higher attrition, and support data-driven employee retention decisions.

## 🛠️ Tech Stack
- 📊 **Microsoft Power BI** – Dashboard development and data visualisation
- 🔄 **Power Query** – Data cleaning and transformation
- 📐 **DAX (Data Analysis Expressions)** – Calculated measures and KPI development
- 📁 **Microsoft Excel / CSV** – Dataset handling

## 📂 Data Source
- Dataset Name: IBM HR Analytics Employee Attrition & Performance
- Source: Kaggle
- Dataset Link: https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset
- Records: 1,470 employee records
- Columns: 35 employee-related attributes
- Data Type: Sample HR dataset used for learning and analysis purposes.

## ✨ Features and Highlights

### 📈 1. Workforce Overview
- 👥 Total Employees: 1,470
- ✅ Active Employees: 1,233
- 🚪 Attrition Count: 237
- 📉 Attrition Rate: 16.12%
- 💰 Average Monthly Income: 6,502.93
- 📅 Average Tenure: 7.01 years

### 🔍 2. Employee Attrition Deep Dive
- Department-wise attrition analysis
- Age-group attrition analysis
- Overtime-based attrition comparison
- Job satisfaction analysis
- Marital status analysis
- Department and job role comparison using a matrix

### 💡 3. Key Business Insights
- 🏢 Sales department has the highest attrition rate at 20.63%.
- 👩‍💼 Employees under 30 have the highest age-group attrition rate at 27.91%.
- ⏰ Employees working overtime show a higher attrition rate (30.53%) compared with employees not working overtime (10.44%).

### 🎛️ 4. Interactive Dashboard
- Two dashboard pages with navigation buttons
- Department and Job Role slicers
- Interactive charts, KPI cards, and visual comparisons
- Key business insights and HR recommendations

### 🎯 5. Business Recommendations
- Review overtime workload and employee well-being.
- Develop retention strategies for the Sales department.
- Provide additional engagement and career support for younger employees.
